# Notices

`rusty_exr` is an independent Rust implementation of the OpenEXR file
format. It is not affiliated with the OpenEXR project or the Academy
Software Foundation.

The compression algorithms (the RLE and ZIP predictors, PIZ's wavelet and
16-bit Huffman coder, PXR24's 24-bit float rounding, B44/B44A, and the DWA
lossy DCT coder) follow the OpenEXR reference implementation, and DWA's
inverse DCT reproduces the operation order of OpenEXR's AVX routine so that
decoded samples match it bit for bit. `src/luts.z` holds four lookup tables
generated by OpenEXR 3.5.5 (B44's log/exp transfer and DWA's perceptual
transfer), stored compressed.

Where the writer chooses bytes (attribute order, the Huffman tree's tie
order, PIZ's empty-bitmap encoding, deflate at level 4), it follows the
`exrs` crate (`exr` on crates.io) so that its files are byte-identical to
that crate's. No source was copied from either project.
